# LoRA Fine-tuning (Experimental)

This folder contains **experimental LoRA fine-tuning code** for the Reason-Code project.

⚠️ **Important Note**  
The LoRA experiments are **NOT used** in the main paper results.  
All reported results in the paper are based on **zero-shot / inference-time methods only**.

## Purpose
- Explore whether lightweight fine-tuning can further improve repair behavior
- Investigate compatibility between LoRA and MCTS-based reasoning

## Status
- Prototype implementation
- Preliminary experiments only
- Not included in any benchmark tables or figures

## Contents
- `finetune_lora.py`: LoRA fine-tuning script
- `model_card_draft.md`: Draft model card (for documentation only)

# Experimental Components

This directory contains legacy, exploratory, or demo-level implementations,
including alternative model backends and routing strategies.

These components are **not used** in the main experiments reported in the paper
and are provided for reference only.

## Disclaimer
This directory is kept for research completeness and future work.
